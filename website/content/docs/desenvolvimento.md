O Nanci é código aberto ([GPL-3.0](https://github.com/vasfvitor/nanci/blob/main/LICENSE)), em Go, com o desktop em [Wails](https://wails.io/) e Vue 3. A documentação para desenvolvedores fica no repositório:

- [DEVELOPMENT.md](https://github.com/vasfvitor/nanci/blob/main/docs/DEVELOPMENT.md): ambiente, build e instalador.
- [CONTRIBUTING.md](https://github.com/vasfvitor/nanci/blob/main/CONTRIBUTING.md): estrutura, padrões e testes.
- [ARCHITECTURE.md](https://github.com/vasfvitor/nanci/blob/main/docs/ARCHITECTURE.md): pacotes e sincronização.
- [NFSE_ADN.md](https://github.com/vasfvitor/nanci/blob/main/docs/NFSE_ADN.md), [NFE_SEFAZ.md](https://github.com/vasfvitor/nanci/blob/main/docs/NFE_SEFAZ.md) e [CTE_SEFAZ.md](https://github.com/vasfvitor/nanci/blob/main/docs/CTE_SEFAZ.md): cada integração.
